# การตรวจสอบข้อมูลสมัครสมาชิกและความปลอดภัยการเข้าสู่ระบบ

ปรับปรุงวันที่ 21 สิงหาคม 2569

## สมัครสมาชิกนักศึกษา

- ชื่อและนามสกุลรับเฉพาะตัวอักษร Unicode รวมถึงภาษาไทยและอังกฤษ
- อนุญาตช่องว่าง จุด อัญประกาศเดี่ยว และขีดกลางเมื่อใช้คั่นส่วนของชื่อ
- ไม่อนุญาตตัวเลขหรือสัญลักษณ์อื่น และจำกัดความยาวไม่เกิน 100 ตัวอักษร
- ตรวจชื่อทั้งในเบราว์เซอร์และฝั่งเซิร์ฟเวอร์
- รหัสนักศึกษารับเฉพาะตัวเลข 12 หลัก นักศึกษาไม่ต้องกรอกขีด และหน้าเว็บจะเติมขีดก่อนเลขหลักสุดท้ายให้อัตโนมัติเป็นรูปแบบ `XXXXXXXXXXX-X`
- ฝั่งเซิร์ฟเวอร์ยอมรับเฉพาะตัวเลข 12 หลักหรือรูปแบบที่จัดขีดถูกต้อง และปฏิเสธตัวอักษร สัญลักษณ์ จำนวนหลักไม่ครบ และขีดผิดตำแหน่ง
- ตรวจอีเมลมหาวิทยาลัย คำนำหน้า ความสัมพันธ์คณะ–สาขา–กลุ่มเรียน รหัสผ่าน และข้อมูลซ้ำฝั่งเซิร์ฟเวอร์
- ฟอร์มและปลายทางสมัครสมาชิกตรวจ CSRF Token

## เข้าสู่ระบบและรหัสผ่าน

- ระหว่างช่วงทดสอบระบบ รหัสผ่านที่สมัคร ตั้ง หรือเปลี่ยนใหม่จะจัดเก็บเป็นข้อความธรรมดาตามข้อกำหนดของผู้พัฒนา
- บัญชีที่ถูก Hash ไปก่อนเปิดโหมดทดสอบยังเข้าสู่ระบบได้ตามปกติ แต่ระบบจะไม่ Hash หรือเขียนทับรหัสผ่านอัตโนมัติระหว่างเข้าสู่ระบบ
- ก่อนนำระบบไปใช้งานจริงต้องเปิดการจัดเก็บแบบ Hash และย้ายรหัสผ่านข้อความธรรมดาทั้งหมด
- ข้อความกรณีไม่พบอีเมลหรือรหัสผ่านผิดใช้ข้อความกลางเดียวกัน
- ฟอร์มเข้าสู่ระบบปกติ เข้าใช้ครั้งแรก OTP สมัครสมาชิก เปลี่ยนรหัสผ่าน และรีเซ็ตรหัสผ่านตรวจ CSRF Token
- ยังคงการเปลี่ยน Session ID หลังยืนยันตัวตน และจำกัดการเข้าสู่ระบบพร้อมกันหนึ่งอุปกรณ์ต่อบัญชี
- ยังไม่เพิ่มการจำกัดจำนวนครั้งที่เข้าสู่ระบบผิดตามข้อยกเว้นของผู้ใช้

## ผลการทดสอบ

- ชื่อภาษาไทย อังกฤษ ชื่อมีขีดกลาง และอัญประกาศเดี่ยวผ่าน
- ชื่อที่เป็นตัวเลข ผสมตัวเลข สัญลักษณ์ หรือตัวอักษรว่างถูกปฏิเสธ
- หน้าเว็บปฏิเสธ `12345` ในช่องชื่อ และยอมรับชื่อภาษาไทย
- การจัดเก็บรหัสผ่านแบบข้อความในโหมดทดสอบ การปฏิเสธรหัสผ่านผิด และความเข้ากันได้กับบัญชีเดิมที่ถูก Hash ผ่านชุดทดสอบ
