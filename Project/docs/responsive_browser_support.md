# มาตรฐาน Responsive และแพลตฟอร์มที่รองรับ

ระบบใช้แนวทาง Responsive Web Design เพื่อให้ใช้งานได้บนโทรศัพท์มือถือ แท็บเล็ต คอมพิวเตอร์ และจอขนาดใหญ่ โดยกำหนดขอบเขตการรองรับที่สามารถทดสอบและอ้างอิงได้ดังนี้

## ขนาดหน้าจอเป้าหมาย

| กลุ่มอุปกรณ์ | ความกว้างหน้าจอที่ใช้ทดสอบ |
|---|---:|
| Mobile | 360–767 px |
| Tablet | 768–1023 px |
| Desktop | 1024–1439 px |
| Large Desktop | 1440 px ขึ้นไป |

ขนาดอ้างอิงสำหรับการทดสอบอย่างน้อยคือ 360, 768, 1024 และ 1440 พิกเซล

## ระบบปฏิบัติการและเบราว์เซอร์

| ระบบปฏิบัติการ | เบราว์เซอร์ที่รองรับ |
|---|---|
| Windows 10 และ Windows 11 | Google Chrome, Microsoft Edge และ Mozilla Firefox |
| macOS | Safari, Google Chrome และ Mozilla Firefox |
| Linux รุ่นปัจจุบัน | Google Chrome และ Mozilla Firefox |
| Android 10 ขึ้นไป | Google Chrome |
| iOS และ iPadOS 15 ขึ้นไป | Safari |

รองรับเบราว์เซอร์รุ่นปัจจุบันและย้อนหลังไม่เกิน 2 รุ่น ระบบไม่รองรับ Internet Explorer และต้องเปิดใช้งาน JavaScript

## ข้อความสำหรับเอกสารปริญญานิพนธ์

ระบบรองรับการแสดงผลแบบ Responsive Web Design สามารถใช้งานผ่านคอมพิวเตอร์ โทรศัพท์มือถือ และแท็บเล็ต โดยรองรับระบบปฏิบัติการ Windows, macOS, Linux, Android และ iOS/iPadOS ผ่านเว็บเบราว์เซอร์ Google Chrome, Microsoft Edge, Mozilla Firefox และ Safari รุ่นปัจจุบันหรือย้อนหลังไม่เกิน 2 รุ่น ทั้งนี้ระบบไม่รองรับ Internet Explorer และจำเป็นต้องเปิดใช้งาน JavaScript

## เกณฑ์ตรวจรับ

1. เนื้อหาหลักต้องไม่ล้นออกนอกหน้าจอโดยไม่มีพื้นที่เลื่อนที่กำหนดไว้
2. Sidebar ต้องเปิดและปิดได้บน Mobile และ Tablet
3. ตารางขนาดกว้างต้องเลื่อนแนวนอนได้โดยไม่ทำให้หน้าเว็บทั้งหน้าล้น
4. ฟอร์ม ปุ่ม และข้อความต้องอ่านและใช้งานได้ที่ความกว้าง 360 px
5. หน้าตัวอย่างเอกสาร PDF สามารถเลื่อนดูได้บนหน้าจอเล็กโดยไม่ทำให้แบบฟอร์มหายไป
6. การทำงานหลักต้องให้ผลเหมือนกันในเบราว์เซอร์ที่กำหนด

## ผลการตรวจวันที่ 21 สิงหาคม 2569

- หน้าเข้าสู่ระบบผ่านการตรวจที่ความกว้าง 360, 768, 1024 และ 1440 px โดยไม่มีเนื้อหาและตัวควบคุมล้นหน้าจอ
- หน้าสมัครสมาชิก หน้าลืมรหัสผ่าน และหน้าเข้าใช้ครั้งแรกผ่านการตรวจที่ความกว้าง 360 px
- โครงสร้างส่วนกลางของ Admin นักศึกษา เจ้าหน้าที่ และอาจารย์โหลดกฎ Responsive เดียวกัน
- Sidebar ของทั้ง 4 บทบาทมีโครงสร้างสำหรับเปิด–ปิดบนหน้าจอขนาดเล็ก
- ตารางขนาดกว้างใช้พื้นที่เลื่อนแนวนอน และหน้ากรอกเอกสารมีพื้นที่เลื่อนตัวอย่าง PDF แยกจากแบบฟอร์ม
- การตรวจบน Safari, Firefox และอุปกรณ์จริงให้ดำเนินการในขั้นทดสอบความเข้ากันได้ก่อนนำระบบขึ้นใช้งานจริง
