7. การลงนามทั้งหมดดำเนินการกับเอกสารฉบับพิมพ์นอกระบบ
8. เจ้าหน้าที่รับผิดชอบเฉพาะเอกสารและข้อมูลฝึกประสบการณ์วิชาชีพ รวมถึงแผนนิเทศครั้งที่ 1 และ 2 และการส่งออก Excel
9. Admin จัดการบัญชี สิทธิ์ ข้อมูลพื้นฐาน ผู้ดำรงตำแหน่ง ผู้เกี่ยวข้อง และตรวจสอบประวัติการพิจารณา
10. ระบบใช้ Responsive Web Design รองรับ Mobile, Tablet, Desktop และ Large Desktop บนเบราว์เซอร์สมัยใหม่ตาม `docs/responsive_browser_support.md`
